# Icewfuzzy – Anime-Tsundere-Begleiterin (Fabric, MC 1.21.11)

Zwei Teile:
1. Mod (dieses Projekt): Verhalten, Dialoge, Menü.
2. Resource Pack (Icewfuzzy-ResourcePack.zip): Aussehen. Skins in assets/icewfuzzy/textures/entity/icewfuzzy_0..3.png
   (64x64) einfach durch eigene ersetzen.

Bauen: gradle.properties-Versionen sowie gradlew, gradlew.bat und gradle/ aus Neoloni-Styles übernehmen, dann build.bat.

Im Spiel: Taste K öffnet das Menü (Aussehen, Folgen, Abstände, Sprüche, Charakter, Beschwören/Entfernen).
Rechtsklick auf Icewfuzzy = Interaktion. Taste K ist unter Steuerung -> Icewfuzzy änderbar.
